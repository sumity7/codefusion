
# CodeNest — Project Build Prompt

Build a premium React marketplace called CodeNest for original UI products/components.

Visual direction:
- Take only the visual language, spacing philosophy, editorial product presentation and color mood from the referenced VAYUÉ site.
- Do NOT copy its content, names, branding, images, text, product information or proprietary UI.
- Final brand palette: deep black/charcoal with sophisticated lavender accents.
- Product-first, premium editorial feel rather than a generic SaaS dashboard.
- Strong hover micro-interactions and scroll-reveal motion.
- Responsive composition for large desktop, desktop/laptop, tablet and mobile.

Product marketplace:
- 10 original, genuinely usable products.
- Each product must have a distinct purpose and distinct interface.
- Product listing, search, category filters, collections and product detail pages.
- Product detail includes preview, gallery-ready structure, description, features, specifications, compatibility, versions/changelog, reviews and source.
- Product preview and source code must use one source of truth for source-synchronized products.
- One unified source-code window only.
- One "Copy all code" button copies complete HTML + CSS + JS in one action.
- One-click download of the complete standalone implementation.
- Generated/recreation prompt is available per product and can be copied in one click.

Commerce/account:
- Login
- Register
- Password recovery
- Account/profile
- Wishlist
- Purchases
- Downloads
- Checkout-ready architecture
- Reviews and review moderation

Admin:
- Dashboard
- Products
- Add product
- Edit product
- Delete product
- Publish/unpublish
- Categories
- Orders
- Users
- Reviews
- Downloads
- Analytics
- Coupons

Backend:
- Node.js + Express
- MongoDB + Mongoose
- JWT authentication
- bcrypt password hashing
- Admin role
- REST API
- Real CRUD persistence
- Source authorization for premium products
- API error handling and rate limiting
- Production-safe environment variables

UI behavior:
- Buttons can open accessible animated modal/popups where an action needs confirmation or quick preview.
- Close via X, outside click and Escape.
- Keyboard focus support.
- Respect prefers-reduced-motion.
